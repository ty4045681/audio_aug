# raw/ — 原始音频（只读）

把原始 **16-bit PCM WAV** 放在这里，可按说话人 / 数据集分子目录，例如：

```text
raw/
├── speaker001/
│   ├── 0001.wav
│   └── 0002.wav
└── speaker002/
    └── 0001.wav
```

- 这个目录的内容**永不被脚本修改或覆盖**。
- 脚本会保留这里的相对路径与文件名，把结果写到 `runs/<批次>/audio/` 下对应位置。
- 当前包含 `speaker001/0001.wav`、`0002.wav` 两个示例正弦音用于自测，可删除后换成真实数据。
